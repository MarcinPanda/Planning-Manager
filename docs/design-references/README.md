# Opisy wyglądu (inspiracja)

Opisy stylów z repozytorium [rohitg00/awesome-claude-design](https://github.com/rohitg00/awesome-claude-design)
(licencja MIT, patrz `LICENSE-awesome-claude-design`). Rodzina „data-dense" (Datadog, ClickHouse, MongoDB, PostHog)
i Linear – gęste, techniczne panele bez ozdobników, czyli to, czym ma być tablica Monitoring.

Tylko inspiracja przy zmianach wyglądu (`pm/theme.py`); aplikacja nie kopiuje żadnej marki.
